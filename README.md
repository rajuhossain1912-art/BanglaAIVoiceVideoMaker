# বাংলা AI Voice Video Maker

An online-only, TalkBack-friendly Android app for turning Bangla, English, or mixed-language text—or a script plus a supplied voice recording—into a video.

## চূড়ান্ত লক্ষ্য

- শুধু বাংলা/ইংরেজি লেখা দিলে স্বয়ংক্রিয় ভয়েস ও ভিডিও তৈরি
- লেখা ও নিজের অডিও দিলে কথার সঙ্গে সাবটাইটেল মেলানো
- বিষয় অনুযায়ী ছবি/দৃশ্য, শিরোনাম, জুম, ট্রানজিশন ও শব্দ হাইলাইট
- MP4 তৈরি, ফোনে সংরক্ষণ ও শেয়ার
- TalkBack-সহায়ক বাংলা ইন্টারফেস
- অনলাইন-নির্ভর ব্যবহার; অফলাইন মোড নেই
- বিনামূল্যের ও ওপেন-সোর্স প্রযুক্তি অগ্রাধিকার; অনুমতি ছাড়া পেইড সেবা নয়

## প্রাথমিক বাস্তবায়ন

- Android Jetpack Compose UI
- FastAPI সার্ভার
- FFmpeg দিয়ে MP4 রেন্ডারিং
- espeak-ng দিয়ে প্রাথমিক ওপেন-সোর্স TTS
- Pillow দিয়ে গ্রাফিক পটভূমি
- অডিও থাকলে আপলোড; না থাকলে সার্ভারে TTS
- বাক্যভিত্তিক আনুমানিক সাবটাইটেল
- GitHub Actions-এ APK বিল্ড
- Render-এর ফ্রি Docker Web Service-এর জন্য প্রাথমিক Blueprint

## বর্তমানে যাচাইকৃত সুবিধা

- বাংলা, ইংরেজি এবং একই লেখার মধ্যে বাংলা-ইংরেজি মিশ্র অংশের জন্য আলাদা eSpeak NG কণ্ঠ ব্যবহার করে অডিও তৈরি
- GitHub Actions-এ বাংলা, ইংরেজি ও মিশ্র-ভাষার MP4 তৈরি, ডাউনলোড এবং ffprobe যাচাই সফল
- Android debug APK তৈরি হয়েছে; সর্বশেষ বিল্ডের জন্য GitHub Actions-এর Build Android APK রান দেখুন

## গুরুত্বপূর্ণ সীমাবদ্ধতা

এই সংস্করণটি এখনও সম্পূর্ণ AI ভিডিও নির্মাতা নয়। এটি একটি প্রাথমিক ভিডিও-রেন্ডারিং প্রোটোটাইপ: AI-তৈরি বিষয়ভিত্তিক বাস্তব দৃশ্য, নির্ভুল শব্দ-স্তরের অডিও-টেক্সট alignment, স্থায়ী job storage এবং উচ্চমানের বাংলা TTS এখনও পরবর্তী কাজ। espeak-ng কণ্ঠ রোবোটিক শোনাতে পারে। Render-এর ফ্রি সার্ভার ঘুমিয়ে যেতে পারে এবং অস্থায়ী কাজ/ফাইল পুনরায় চালু হলে হারাতে পারে।

**নিজের কণ্ঠে লেখা পড়ার পরীক্ষামূলক সুবিধা:** অ্যাপে এখন আলাদা `পরীক্ষামূলক: আমার কণ্ঠে লেখা পড়ুন` পদ্ধতি যোগ হয়েছে। এটি বাংলা CosyVoice3-এর Hugging Face ডেমো ব্যবহার করে; একবারে সর্বোচ্চ ৫০০ অক্ষর। চালু করার আগে অ্যাপ বাহ্যিক সার্ভারে কণ্ঠের নমুনা পাঠানোর স্পষ্ট সম্মতি চাইবে। নমুনা তৃতীয় পক্ষের সার্ভারে পাঠানো হয়, তাই তাদের লগ/সংরক্ষণ সম্পর্কে আমরা নিশ্চয়তা দিতে পারি না—ব্যক্তিগত বা গোপন অডিও ব্যবহার করবেন না। অ্যাপের Render সার্ভার নিজের কাছে থাকা নমুনা অডিও ক্লোনের অনুরোধের পর মুছে ফেলার চেষ্টা করে। বাহ্যিক ডেমো ব্যস্ত, বদলে যাওয়া বা বন্ধ থাকলে ক্লোনিং ব্যর্থ হতে পারে। বাংলা-ইংরেজি মিশ্র লেখা ও ইংরেজি কণ্ঠের মান এখনো নিশ্চিত নয়; বাস্তব নমুনা দিয়ে আলাদা পরীক্ষা বাকি। মডেল: [Bengali CosyVoice3 TTS](https://huggingface.co/kawshikbuet17/bengali-cosyvoice3-tts), Apache-2.0; ডেমো: [Hugging Face Space](https://huggingface.co/spaces/kawshikbuet17/bengali-cosyvoice3-tts-demo). Render-এর Free প্ল্যানে বড় voice-cloning মডেল নিজে চালানো সম্ভব নয়; কোনো পেইড পরিষেবা চালু করা হয়নি।
