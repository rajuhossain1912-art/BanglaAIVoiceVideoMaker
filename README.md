# বাংলা AI Voice Video Maker

An online-only, TalkBack-friendly Android app for turning Bangla, English, or mixed-language text—or a script plus a supplied voice recording—into a video.

## চূড়ান্ত লক্ষ্য

- শুধু বাংলা/ইংরেজি লেখা দিলে স্বয়ংক্রিয় ভয়েস ও ভিডিও তৈরি
- লেখা ও নিজের অডিও দিলে কথার সঙ্গে সাবটাইটেল মেলানো
- বিষয় অনুযায়ী ছবি/দৃশ্য, স্বয়ংক্রিয় জুম-প্যান এবং শব্দ হাইলাইট
- MP4 তৈরি ও ফোনের Downloads ফোল্ডারে সংরক্ষণ
- TalkBack-সহায়ক বাংলা ইন্টারফেস
- অনলাইন-নির্ভর ব্যবহার; অফলাইন মোড নেই
- বিনামূল্যের ও ওপেন-সোর্স প্রযুক্তি অগ্রাধিকার; অনুমতি ছাড়া পেইড সেবা নয়

## প্রাথমিক বাস্তবায়ন

- Android Jetpack Compose UI
- FastAPI সার্ভার
- FFmpeg দিয়ে MP4 রেন্ডারিং
- Google TTS অনলাইন ভয়েস; ব্যর্থ হলে espeak-ng স্থানীয় fallback
- Pillow ও FFmpeg দিয়ে দৃশ্যভিত্তিক ভিডিও; Cloudflare Workers AI, Pollinations এবং Hugging Face-এর ফ্রি ইমেজ মডেল চেষ্টা; প্রয়োজনে Openverse/Wikimedia-র লাইসেন্সযুক্ত ছবি, শেষে বিষয়ভিত্তিক গ্রাফিক fallback
- অডিও থাকলে আপলোড; না থাকলে সার্ভারে TTS
- অডিওর নীরব বিরতি শনাক্ত করে বাক্যের সময় নির্ধারণের চেষ্টা; তারপর শব্দ-হাইলাইট সাবটাইটেল
- GitHub Actions-এ APK বিল্ড
- Render-এর ফ্রি Docker Web Service-এর জন্য প্রাথমিক Blueprint

## বর্তমানে যাচাইকৃত সুবিধা

- বাংলা, ইংরেজি এবং মিশ্র লেখার জন্য ভাষাভিত্তিক অংশে Google TTS অনলাইন ভয়েস ব্যবহার; ব্যর্থ হলে eSpeak NG fallback
- GitHub Actions-এ বাংলা, ইংরেজি ও মিশ্র-ভাষার MP4 তৈরি, ডাউনলোড এবং ffprobe যাচাই সফল
- সর্বোচ্চ ৩২টি প্রতিনিধিত্বমূলক দৃশ্যের জন্য Cloudflare Workers AI, Pollinations এবং Hugging Face-এর ছবি-সেবা চেষ্টা করা হয়; ব্যর্থ হলে Openverse/Wikimedia-র অনুমোদিত ছবি এবং শেষে বিষয়ভিত্তিক গ্রাফিক ব্যবহার করা হয়। ছবির প্রাসঙ্গিকতা নিখুঁত হওয়ার নিশ্চয়তা নেই
- ৩, ৫, ১০, ১৫ ও ২০ সেকেন্ডে দৃশ্য পরিবর্তনের পছন্দ আছে; ডিফল্ট ৩ সেকেন্ড। Settings থেকে সাবটাইটেল অডিওর তুলনায় -১.৫ থেকে +১.৫ সেকেন্ড সরানো যায়। অডিওর বিরতি পাওয়া গেলে বাক্য-সময় আরও ভালোভাবে মেলানো হয়; প্রতিটি শব্দের সময় এখনও আনুমানিক, প্রকৃত forced alignment নয়
- সাবটাইটেল-সময় ঠিক করার জন্য ব্যবহারকারীকে হাতে কিছু করতে হয় না; অডিওতে উপযুক্ত বিরতি না থাকলে শব্দের সময় আনুমানিক হতে পারে
- Android APK GitHub Actions-এ তৈরি ও GitHub Release-এ প্রকাশ করা হয়; সর্বশেষ সংস্করণ GitHub Releases পৃষ্ঠায় প্রকাশিত

## গুরুত্বপূর্ণ সীমাবদ্ধতা

এই সংস্করণে Cloudflare Workers AI, Pollinations এবং FLUX.1-schnell ও Z-Image-Turbo-এর ফ্রি Hugging Face Space চেষ্টা করা হয়, কিন্তু এটি বিনামূল্যের শেয়ারড GPU-র ওপর নির্ভর করে; ব্যস্ত বা বন্ধ থাকলে গ্রাফিক ব্যাকগ্রাউন্ড ব্যবহার হয়। বিষয়ের সঙ্গে ছবির মিল নিখুঁত হওয়ার নিশ্চয়তা নেই। সাবটাইটেলের বাক্য-সময় অডিওর নীরব বিরতি থেকে শনাক্ত করার চেষ্টা করা হয়; প্রতিটি শব্দের সময় এখনও অনুমানভিত্তিক, বিশেষত দ্রুত কথা, বিরতিহীন কথা বা আলাদা আপলোড করা অডিওতে। তাই ব্যবহারকারীকে হাতে সময় ঠিক করতে হয় না, কিন্তু একেবারে নিখুঁত word-level forced alignment এখনও যুক্ত হয়নি। স্থায়ী job storage এবং উচ্চমানের বাংলা TTS এখনও সীমাবদ্ধতা। আলাদা title card, animated scene transition এবং অ্যাপের ভেতর সরাসরি social sharing এখনো যুক্ত হয়নি। GitHub Releases-এর APK হলো debug build; এটি Google Play Store-এর production-signed APK নয়। সার্ভার এক সময়ে একটি ভিডিওর কাজ গ্রহণ করে; সম্পন্ন/ব্যর্থ কাজের ফাইল সাধারণত ২৪ ঘণ্টা পরে পরিষ্কার করা হয়, তবে Render পুনরায় চালু হলে তার আগেই অস্থায়ী কাজ হারাতে পারে। espeak-ng কণ্ঠ রোবোটিক শোনাতে পারে। Render-এর ফ্রি সার্ভার ঘুমিয়ে যেতে পারে এবং অস্থায়ী কাজ/ফাইল পুনরায় চালু হলে হারাতে পারে।

**নিজের কণ্ঠে লেখা পড়ার পরীক্ষামূলক সুবিধা:** অ্যাপে `পরীক্ষামূলক: আমার কণ্ঠে লেখা পড়ুন` পদ্ধতিতে ফোনের মাইক্রোফোন দিয়ে কণ্ঠ রেকর্ড করে অ্যাপের ব্যক্তিগত স্টোরেজে সংরক্ষণ করার সুবিধা আছে; অডিও ফাইল বেছে নেওয়ার বিকল্পও আছে। বাংলা বা মিশ্র লেখার জন্য [Bengali CosyVoice3](https://huggingface.co/spaces/kawshikbuet17/bengali-cosyvoice3-tts-demo) এবং শুধু ইংরেজি লেখার জন্য [Chatterbox](https://huggingface.co/spaces/ResembleAI/Chatterbox) ডেমো চেষ্টা করা হয়; ইংরেজি ডেমো ব্যর্থ হলে CosyVoice3 বিকল্প হিসেবে চেষ্টা হয়। একবারে সর্বোচ্চ ৩০০০ অক্ষর। চালু করার আগে স্পষ্ট সম্মতি দিতে হবে। কণ্ঠের নমুনা ফোনে থাকে, কিন্তু ক্লোন তৈরি করতে প্রতিবার স্বয়ংক্রিয়ভাবে বাহ্যিক ডেমোতে পাঠাতে হয়—এই ফ্রি ডেমোগুলো স্থায়ী ব্যক্তিগত voice-clone model সংরক্ষণের ব্যবস্থা দেয় না। তাদের লগ/সংরক্ষণ সম্পর্কে নিশ্চয়তা নেই, তাই গোপন বা ব্যক্তিগত অডিও ব্যবহার করবেন না। বাহ্যিক ডেমো ব্যস্ত, বদলে যাওয়া বা বন্ধ থাকলে ক্লোনিং ব্যর্থ হতে পারে। বাংলা-ইংরেজি মিশ্র লেখা, ইংরেজি উচ্চারণ ও একই কণ্ঠের সাদৃশ্যের মান এখনও নিশ্চিত নয়। [CosyVoice3 মডেল](https://huggingface.co/kawshikbuet17/bengali-cosyvoice3-tts) Apache-2.0 লাইসেন্সের; Render-এর Free প্ল্যানে বড় voice-cloning মডেল নিজে চালানো সম্ভব নয়। কোনো পেইড পরিষেবা চালু করা হয়নি.

## গোপনীয়তা ও সীমা

- অ্যাপ অনলাইনে কাজ করে; লেখা, ভিডিও তৈরির অনুরোধ এবং বেছে নেওয়া অডিও Render সার্ভারে পাঠানো হয়।
- কণ্ঠের নমুনা ফোনের ব্যক্তিগত অ্যাপ স্টোরেজে থাকে এবং অ্যাপ থেকে মুছে ফেলা যায়। ক্লোনিং চালালে সেই নমুনা প্রতিবার বাহ্যিক ডেমোতে স্বয়ংক্রিয়ভাবে পাঠানো হয়, তাই ব্যবহারকারীকে প্রতিবার ফাইল নির্বাচন করতে হয় না। এটি স্থায়ী ক্লোন মডেল নয়। সাধারণ অডিও ন্যারেশন ভিডিও তৈরি হওয়ার পর সার্ভারের কাজের ফোল্ডার থেকে মুছে ফেলার চেষ্টা করা হয়। সার্ভার ব্যর্থ হলে বা হোস্টিং/লগিং স্তরে অন্য কপি থাকলে সম্পূর্ণ মুছে যাওয়ার নিশ্চয়তা নেই।
- নিজের কণ্ঠ ক্লোনিং বেছে নিলে কণ্ঠের নমুনা ও লেখা আলাদা বাহ্যিক Hugging Face ডেমোতে পাঠানো হয়। তৃতীয় পক্ষের সংরক্ষণ/লগিং সম্পর্কে নিশ্চয়তা নেই। গোপন বা সংবেদনশীল অডিও দেবেন না এবং শুধু নিজের বা অনুমতিপ্রাপ্ত কণ্ঠ ব্যবহার করুন।
- Render Free-তে সার্ভার ঘুমিয়ে যেতে পারে; বড়/দীর্ঘ ভিডিও, ছবি অনুসন্ধান বা বাহ্যিক ক্লোনিং ব্যর্থ হতে পারে। কোনো পেইড API বা পেইড Render প্ল্যান ব্যবহার করা হচ্ছে না।
